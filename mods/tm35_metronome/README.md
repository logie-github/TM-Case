# TM35 Metronome

Add gesture controls to overwrite the main touch controls.

## Controls

- Tap = A
- Swipe from the right edge = B
- Swipe up from the bottom edge = Start
- Two-finger tap = Select
- Swipe and hold a direction = D-pad, held

## Setup

Enable `tm35_metronome` under `mods` in `options.lua`, or through the F10
mod manager. Then open the mod's options (F10) and set TOUCH INPUT to
SWIPE. That switches the on-screen pad off for you, so it's one setting
instead of two.
